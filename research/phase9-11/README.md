# DPI Runtime — Phase 9–11 Research Archive

This directory preserves the later systems-level research that evolved from
the DPI Runtime experiments.

It is intentionally separated from the core DPI Runtime architecture so that
the main repository retains a clear measurement-observability narrative.

## Research Progression

## Research Components

### Detector State
- semantic state
- prediction state
- coherence
- trust relationships

### Federation
Combines multiple detector states into a shared system field.

### Topology
Models relationships among detector entities and local neighborhoods.

### Civilization Regions
Explores region formation, regional fields, and detector migration.

### Distributed Memory
Stores and retrieves historical semantic-state information.

### Consensus
Explores recursive convergence of detector states toward federation-level
structure.

### Trust Ecology
Models pairwise trust relationships based on detector-state coherence.

### Governance
Explores system-level regulation using coherence and stability targets.

### Constitutional Evolution
Tracks the evolution of governance policies over time.

### Inheritance
Archives prior system epochs and retrieves historical state information.

### Diplomacy
Models relationships between regions and evolving alliance structures.

### Meta-Governance
Evaluates governance-system stability and modifies higher-level regulation.

### Observer Engine
Introduces observer-derived system fields and recursive feedback.

### Quantum Integrator
Combines system fields and observer signals into an integrated coherence state
and redistributes feedback to detector entities.

## Scope

These modules are exploratory systems-research extensions.

They should not be interpreted as part of the minimal DPI Runtime core, nor as
production implementations of distributed control, governance, or quantum
hardware infrastructure.

The archive is retained because it documents the progression from single
detector observability toward multi-entity state integration.
